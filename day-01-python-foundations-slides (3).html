11
Loops

Python loops favor iterating over the thing you need.

# for: iterate over values
for task in tasks:
    print(task)

# range: generate numbers
for i in range(3):
    print(i)

# while: repeat while true
attempts = 0
while attempts < 3:
    attempts += 1
# break: leave the loop
for task in tasks:
    if task == "build":
        break

# continue: skip this iteration
for task in tasks:
    if task == "practice":
        continue
    print(task)
Prefer
for item in items
rather than manually managing indexes when you don't need them.
Need index?
enumerate(items)
introduced in the Pythonic basics cheatsheet.
Gotcha: changing a collection while iterating over it can produce surprising behavior. Prefer building a new collection when transforming data.

Type hints & strings

Type hints document intent; f-strings make output pleasant to write.

Type hints
def calculate_total(
    prices: list[float],
    tax: float = 0.0,
) -> float:
    return sum(prices) * (1 + tax)
  • Improve readability.
  • Help IDEs and static-analysis tools.
  • Do not automatically enforce runtime types.
f-strings
name = "Alex"
score = 95

f"{name} scored {score}%"
f"Total: {100 * 1.18:.2f}"
f"{name.upper()}"
  • Put expressions directly inside { }.
  • Use format specifiers when needed.
  • Prefer over manual string concatenation.
JS/TS bridge: type hints feel familiar to TypeScript developers, but Python annotations and TypeScript types play different roles at runtime.

16
Python gotchas

These few sharp edges save a lot of debugging time.

1 · Assignment is not copying

a = [1, 2]
b = a
b.append(3)
# a == [1, 2, 3]

Lists are mutable. Two names can reference the same list.

2 · is is not equality

x == y       # same value?
x is y        # same object?

value is None

Use == for value equality; use is for identity.

3 · Mutable default arguments

def add(x, items=[]):
    items.append(x)
    return items

The default list is shared across calls. Prefer items=None and create a list inside.

Notebook gotcha
Cells can run out of order.
A notebook can contain state that is not obvious from the page order.
Language gotcha
Indentation is syntax.
A block's indentation determines its structure.
Truthiness
[] · "" · 0 · None
These values are falsy in conditions.

Guided challenge · recap

Put today's building blocks together in one small piece of logic.

Starting data
tasks = [
    {"title": "Learn Python", "completed": True},
    {"title": "Build something", "completed": False},
    {"title": "Teach someone", "completed": False},
]
Challenge

Create a list containing the titles of the incomplete tasks.

Bonus

Print the results as 1. Build something, 2. Teach someone.

One clean solution
incomplete = [
    task["title"]
    for task in tasks
    if not task["completed"]
]

for i, title in enumerate(incomplete, 1):
    print(f"{i}. {title}")
